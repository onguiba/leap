Frameworks, Outils & Build
Environnement de développement et outils de build
⚡
Vite
v8.0.0-beta.14
Bundler et serveur de développement ultra-rapide. Hot Module Replacement (HMR), build optimisé avec tree-shaking, support natif TypeScript et ES Modules.
Commandes : vite (dev), tsc && vite build (prod)
🔷
TypeScript Compiler
tsc ~5.9.3
Compilateur TypeScript — vérification de types statique, transpilation vers ES2022, configuration via tsconfig.json avec mode strict.
Config : target: ES2020, moduleResolution: bundler
📦
npm
Node Package Manager
Gestionnaire de paquets — installation des dépendances, exécution des scripts de build et de développement.
Scripts : dev, build, preview
3
Bibliothèques Externes
Dépendances npm et CDN utilisées dans l'application
🗺️
Leaflet.js
v1.9.4 — CDN
Bibliothèque de cartographie interactive open-source. Affiche la carte de suivi de livraison avec marqueurs animés (livreur + destination), ligne de route et zoom.
Chargé dynamiquement via unpkg.com dans tracking.ts
🌍
OpenStreetMap
Tuiles gratuites
Fournisseur de tuiles cartographiques open-source. Aucune clé API requise. Utilisé comme fond de carte dans Leaflet. Couverture mondiale incluant le Cameroun.
URL : {s}.tile.openstreetmap.org/{z}/{x}/{y}.png
📷
QuaggaJS
v0.12.1 — npm
Bibliothèque de lecture de codes-barres en JavaScript pur. Supporte EAN-13, EAN-8, Code128, UPC. Fonctionne avec le flux caméra ou une image statique.
Utilisé dans scanner.ts — seule dépendance npm de production
🔤
Inter (Google Fonts)
Variable font
Police typographique premium utilisée dans tout le design system. Poids 400 à 900. Optimisée pour les interfaces numériques, excellente lisibilité sur mobile.
Importée via @import url(fonts.googleapis.com) dans style.css
🖼️
UI Avatars API
API gratuite
Génération d'avatars utilisateur à partir du nom. Utilisé dans la page profil et la carte livreur dans le suivi de commande.
URL : ui-avatars.com/api/?name=…&background=00c471
📲
Web App Manifest
PWA Standard
Fichier manifest.json permettant l'installation de l'application sur mobile comme une app native, sans passer par un store d'applications.
Fichier : public/manifest.json
