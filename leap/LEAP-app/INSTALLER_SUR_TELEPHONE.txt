═══════════════════════════════════════════════════════════════
  OPTION 1: INSTALLATION DIRECTE (PLUS RAPIDE)
═══════════════════════════════════════════════════════════════

Prérequis:
1. Installez Android Studio: https://developer.android.com/studio
2. Connectez votre téléphone en USB
3. Activez le "Mode Développeur" sur votre téléphone:
   - Paramètres → À propos du téléphone
   - Appuyez 7 fois sur "Numéro de build"
   - Retour → Options de développement
   - Activez "Débogage USB"

Installation:
Dans le terminal, depuis leap/LEAP-app:

    npx cap run android

Cela va:
✓ Compiler l'application
✓ Générer l'APK
✓ L'installer automatiquement sur votre téléphone
✓ Lancer l'application

Temps: 3-5 minutes

═══════════════════════════════════════════════════════════════
  OPTION 2: GENERER UN FICHIER APK
═══════════════════════════════════════════════════════════════

Étape 1: Installer Android Studio
- Téléchargez: https://developer.android.com/studio
- Installez (suivez les instructions)
- Temps: 15-20 minutes

Étape 2: Ouvrir le projet
Dans le terminal, depuis leap/LEAP-app:

    npx cap open android

Étape 3: Générer l'APK
Dans Android Studio:
- Menu Build → Build Bundle(s) / APK(s) → Build APK(s)
- Attendez la compilation (2-5 minutes)
- Cliquez sur "locate" pour trouver l'APK

Étape 4: Installer l'APK
L'APK est dans:
    leap/LEAP-app/android/app/build/outputs/apk/debug/app-debug.apk

Copiez ce fichier sur votre téléphone et ouvrez-le pour l'installer.
