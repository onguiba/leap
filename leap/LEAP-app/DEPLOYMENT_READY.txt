================================================================================
                          DÉPLOIEMENT EN 3 ÉTAPES
================================================================================

OPTION 1: VERCEL (Recommandé - Meilleure Performance)
─────────────────────────────────────────────────────
1. git push origin main
2. Allez sur vercel.com → New Project → Importez votre repo
3. Cliquez Deploy
→ Votre site: https://your-project.vercel.app/

OPTION 2: GITHUB PAGES (Gratuit - Simple)
──────────────────────────────────────────
1. git push origin main
2. Settings → Pages → Sélectionnez "GitHub Actions"
3. Attendez le déploiement
→ Votre site: https://YOUR_USERNAME.github.io/LEAP-app/

OPTION 3: NETLIFY (Gratuit - Facile)
────────────────────────────────────
1. git push origin main
2. netlify.com → New site from Git → Sélectionnez votre repo
3. Cliquez Deploy
→ Votre site: https://your-site.netlify.app/
