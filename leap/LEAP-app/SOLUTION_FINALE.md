**Erreur:** `invalid source release: 21`

## ✅ SOLUTION IMMÉDIATE: PWA (30 secondes)

Votre application fonctionne **PARFAITEMENT** comme PWA!

### Sur votre téléphone MAINTENANT:

1. **Ouvrez Chrome** (Android) ou **Safari** (iPhone)

2. **Tapez:**
   ```
   http://192.168.1.96:5174
   ```

3. **Installez:**
   - Android: Menu (⋮) → "Ajouter à l'écran d'accueil"

4. **✅ INSTALLÉ!**

## 🔧 Pour Installation APK Native (Plus Tard)

Si vous voulez vraiment un fichier APK:

### Option 1: Installer Java 21

1. **Téléchargez Java 21:**
   https://adoptium.net/temurin/releases/?version=21

2. **Installez Java 21**

3. **Puis exécutez:**
   ```bash
   cd leap/LEAP-app
   npx cap run android
   ```

### Option 2: Utiliser Android Studio

1. **Téléchargez Android Studio:**
   https://developer.android.com/studio

2. **Installez (inclut Java 21)**

3. **Ouvrez le projet:**
   ```bash
   npx cap open android
   ```

4. **Build → Build APK(s)**
