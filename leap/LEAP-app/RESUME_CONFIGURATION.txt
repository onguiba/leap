│  🛠️ COMMANDES UTILES                                                        │
└──────────────────────────────────────────────────────────────────────────────┘

  Installation:
  .\setup-database.ps1                  Installation automatique complète

  Développement:
  npm run dev:server                    Démarrer le backend (port 3001)
  npm run dev                           Démarrer le frontend (port 5174)

  Base de données:
  npm run db:generate                   Générer le client Prisma
  npm run db:push                       Synchroniser le schéma
  npm run db:seed                       Peupler avec des données de test
  npm run db:studio                     Interface graphique (port 5555)

  PostgreSQL:
  psql -U postgres                      Se connecter à PostgreSQL
  psql -U postgres -d pricecheck        Se connecter à la base pricecheck
